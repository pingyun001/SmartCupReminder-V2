## PCB 原件贴装
推荐焊接顺序：
1. 所有正面贴片原件
2. 除屏幕外，所有背面贴片原件
3. 直插原件（DS18B20温度传感器，微动开关）
4. 屏幕（注意屏幕背面需粘贴双面胶，且双面胶不耐热）
